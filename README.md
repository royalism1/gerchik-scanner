# Сканер уровней по Герчику (США)

Каждый будний вечер после закрытия Нью-Йорка GitHub Actions запускает `scan.py`:

1. Вселенная — все обыкновенные акции NASDAQ и NYSE (без ETF, фондов, ADR, SPAC, варрантов, привилегированных).
2. Фильтры: цена > $5, объём дня > 500K, средний объём 90 дн. > 500K, ATR(14) > 0,5.
3. Уровни — только старшие ТФ: дневка за 6 мес. + неделька (6 мес. основное окно, год — для исторических/зеркальных).
   Тип по Герчику (излом тренда, зеркальный, исторический, ЛП, лимитный игрок, паранормальный бар, граница гепа)
   и сила 1–7 (F8: +1 круглая цена, +1 граница гепа, +1 видна на недельке, −2 «пилится»).
4. Бар у сильного уровня (сила ≥ 4): закрытие ≤ 0,3 ATR от уровня или касание и закрытие ≤ 0,5 ATR.
   Остальные акции пропускаются. В файл попадают все до 0,5 ATR (для статистики по расстоянию).
5. Признаки для предпосылок: свободная/заражённая зона, ближний/дальний ретест, закрытие у хая/лоя,
   поджатие, длинное движение к уровню, паранормальные бары на подходе, запас хода до следующего уровня, тренд.
6. На следующий вечер — сырые итоги вчерашних кандидатов: сколько ATR прошло вверх/вниз от закрытия.

Результаты: `results/<дата>/summary.json`, свечи `results/<дата>/bars/<тикер>.json`,
оценка `results/eval/<дата>.json`, указатель `results/latest.json`.

Пороги — в `config.json` (меняются только по статистике, с записью в `changes_log`).
Ручной прогон на дату: Actions → scan → Run workflow → date.
